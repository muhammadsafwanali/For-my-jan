STEP 1: Apne laptop par chalana
----------------------------------------------------------------
1. Node.js installed ho (https://nodejs.org — LTS version)
2. Is folder mein terminal kholo aur chalao:

       npm install
       npm run dev

3. Browser mein kholo:  http://localhost:5173

⭐ ABHI test karne ke liye:  http://localhost:5173/?preview
   (12 AM ka lock bypass ho jayega — Shehzadi ko ye mat batana!)

----------------------------------------------------------------
STEP 2: INTERNET PAR DAALO (laptop band ho tab bhi chale) 🌐
----------------------------------------------------------------
Tum WhatsApp par link bhejoge, is liye website ko host karna
zaroori hai. DONO tareeqe FREE hain:

════════ TAREEQA A: VERCEL (GitHub ke saath) ════════
1. https://github.com par FREE account banao
2. "New repository" → naam do (maslan: shehzadi-birthday)
3. Is folder ki saari files upload karo (node_modules CHHOR KAR)
4. https://vercel.com par jaao → "Sign up with GitHub"
5. "Add New Project" → apni repository select karo
6. Vercel khud Vite pehchan lega → bas "Deploy" dabao ✅
7. 1 minute mein link mil jayega:
       https://shehzadi-birthday.vercel.app  (kuch aisa)
8. Ye link WhatsApp par Shehzadi ko bhej do! 💜

════════ TAREEQA B: VERCEL (bina GitHub — CLI) ════════
1. Is folder mein terminal kholo:

       npm install -g vercel
       vercel login        (email se login)
       vercel --prod

2. Jo link mile, wahi WhatsApp par bhejo.

════════ TAREEQA C: NETLIFY (sab se aasaan — drag & drop) ════
1. Is folder mein chalao:   npm run build
2. "dist" naam ka folder ban jayega
3. https://app.netlify.com/drop kholo
4. "dist" folder mouse se utha kar wahan chhor do
5. Foran link mil jayega — WhatsApp par bhejo! 🎉

📱 NOTE: Mic wala feature phone par bhi PERFECT chalega
   (Vercel/Netlify dono https dete hain — https zaroori hai).
